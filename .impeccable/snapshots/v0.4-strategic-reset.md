## 三、Impeccable 通用反 AI-slop 规则 · 跨风格保留清单

以下规则由 Impeccable SKILL.src.md §General Rules + §Absolute Bans 规定,不属于"风格预设",是**质量底线**:

| 类别 | 规则 | 状态 |
|---|---|---|
| Color | 文本对比度 ≥ 4.5:1 / placeholder 同样 4.5:1 | ✅ 跨风格保留 |
| Color | 灰字在彩色背景上用 bg 自色或透明 | ✅ 跨风格保留 |
| Typography | body line-length ≤ 65-75ch | ✅ 跨风格保留 |
| Typography | 字体配对比(serif + sans / geometric + humanist) | ✅ 跨风格保留 |
| Typography | hero display ≤ 6rem | ✅ 跨风格保留 |
| Typography | display tracking ≥ -0.04em | ✅ 跨风格保留 |
| Typography | `text-wrap: balance` h1-h3 / `pretty` 长文 | ✅ 跨风格保留 |
| Layout | 间距节奏变化 | ✅ 跨风格保留 |
| Layout | cards 不是默认答案 | ✅ 跨风格保留 |
| Layout | 1D flex / 2D grid 区分 | ✅ 跨风格保留 |
| Layout | `repeat(auto-fit, minmax(280px, 1fr))` | ✅ 跨风格保留 |
| Layout | 语义化 z-index scale(不用 999/9999) | ✅ 跨风格保留 |
| Motion | ease-out-quart / quint / expo(无 bounce/elastic) | ✅ 跨风格保留 |
| Motion | reduced-motion 媒体查询强制 | ✅ 跨风格保留(也是 WCAG 2.3.3 强制) |
| Motion | reveal 默认可见,scroll 仅做 opacity | ✅ 跨风格保留 |
| Motion | 高级动效材质(blur / backdrop-filter / clip-path / mask)按需 | ✅ 跨风格保留 |
| Interaction | dropdown 不被 overflow clip | ✅ 跨风格保留 |
| Anti-AI-slop | 侧边条 / 渐变文字 / 玻璃拟态默认 / hero-metric / 同尺寸卡片网格 / eyebrow 默认 / 阿拉伯编号默认 / 文本溢出 / 图像 hover transform / ghost-card / 圆角 ≥24px / 手绘 SVG / 条纹背景 / 装饰网格 / 元批评 | ✅ 跨风格保留 |
