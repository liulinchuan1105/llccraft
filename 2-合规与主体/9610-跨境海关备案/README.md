# 9610 备案

> 走 **9610 跨境电商零售出口**，海关备案是最后一关。
> 办完了，你就完成了"大陆独立站卖美国瓷器"的全部合规闭环。
> **状态**：🟡 待办 ｜ **预计完成**：本月内

- 各种申报材料的电子档（合同模板、装箱单模板）

## 必须办的顺序

### 第 1 步：海关收发货人（报关单位）备案
- 渠道：**中国国际贸易单一窗口**（https://www.singlewindow.cn/） 或 **广州单一窗口**（gz.gd.singlewindow.cn）
- 拿到 **C0 编号**（9610 报关的前提，电子证书）
- 材料：营业执照、法人身份证、对公账户开户许可

### 第 2 步：广州跨境电商公服平台 + 单一窗口账号
- 用 C0 编号注册**跨境电商企业**身份
- 做"三单（订单 / 物流 / 支付）"登记的基础

### 第 3 步：电子税务局
- 办**无票免税备案**（你 9610 模式免增值税）
- 办**核定征收备案**（企业所得税应税所得率 4%）

## 可不办的（量大了再说）
- **货物贸易外汇名录登记**：年收付汇 < 20 万美元可免办（汇发〔2024〕11 号）
  - 你起步阶段远不到这阈值，**先不管**
