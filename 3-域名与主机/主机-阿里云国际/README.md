## 跨境 2C 卖美国 = 节点的命门

美国客户访问你站，大部分流量从美国过来。**节点离美国越近越好**：

| 节点 | 适合 | 价格 | 我的建议 |
|---|---|---|---|
| **美西（硅谷）** | 卖美国主力推荐 | 中 | ✅ **首推**——你主要客户在美国西海岸，延迟 < 150ms |
| **香港** | 卖东南亚 / 国内也兼顾 | 中低 | 备用——如果你兼顾国内市场 |
| **新加坡** | 卖东南亚 | 中 | 跳过——你主要市场不是这 |
| **东京** | 卖日本 | 中 | 跳过 |

> 如果你想"开机美国节点又兼顾国内管理面板的便利"，**美西优先级远高于香港**。

## WP 跨境 2C 起步配置推荐

| 配置 | 起步 | 我的判断 |
|---|---|---|
| **CPU** | 2 vCPU | ✅ 够开局，访问量起来再升 4 vCPU |
| **内存** | 2 GB | ✅ WordPress 跑 WooCommerce 推荐基线 |
| **系统盘** | 40 GB SSD | ✅ 系统 + WP + 媒体都够 1-2 年 |
| **带宽** | 5 Mbps 固定 / 或 按流量 | ✅ 起步流量小，固定带宽比按流量省钱 |
| **流量** | 1 TB / 月 | ✅ 跨境图片站，1TB 是基础 |
| **系统镜像** | **Ubuntu 22.04 LTS 64 位** | ✅ WP 教程默认 Linux；避开 Windows |
| **预装应用** | **不勾** LAMP / WordPress | 自己装更可控（用宝塔面板） |

**预估成本**：美西节点 2vCPU 2GB ≈ **$25-35/月**（≈¥180-250/月）

## 为什么"自己装"不选预装镜像
- 预装的 WordPress 镜像版本老旧
- 自己装 + 宝塔面板，后续备份、SSL、加插件更可控
