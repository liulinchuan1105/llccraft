### 三段式 SOP（写死照做）

#### 段一 · 备份（迁之前的安全网）

1. **阿里云控制台** → 本实例 → 快照 → 创建系统盘快照，命名 `llccraft-pre-uswest-2026-07-XX`
2. **宝塔面板** → 网站 → 备份：开每日自动备份 + 数据库每日自动 dump（保留 7 天）
3. **全站文件打包**：`tar czf /backup/llccraft-full-$(date +%F).tar.gz /www/wwwroot/llccraft.com`
4. **数据库 dump**：`mysqldump -uroot -p wp_db | gzip > /backup/wp_db-$(date +%F).sql.gz`
5. **`.tar.gz` + `.sql.gz` 通过 `scp` 拉到老板本机加密盘**（别走公众网盘）

#### 段二 · 美西硅谷新机购入

- **节点**：US West (Silicon Valley)
- **规格**：2 vCPU / 2 GB / 40 GB SSD / 5 Mbps（与 Task 002 看板口径一致）
- **系统**：Ubuntu 22.04 LTS 64-bit
- **安全组**：从新加坡机复制规则（端口 + IP 白名单）
- **偷懒捷径**：用新加坡机"快照创建自定义镜像" → 美西新机直接用该镜像 → 5 分钟起机，系统原样搬

#### 段三 · DNS 解析切换（最关键一刀）

1. **前置 1 天**：阿里云 DNS 把 llccraft.com 的 A 记录 TTL 从 `7207` → `300`（让全球 DNS 缓存快速失效）
2. **当天凌晨**：把 A 记录从 `8.219.190.222` 改成美西新 IP
3. 全球生效最长 48h，最快 5-15min（看 TTL 是否提前降）
4. 美西机稳 24h → 把 TTL 改回 `3600`（日常值）
5. 上 SSL（Let's Encrypt 一键）+ 验证 WP / WooCommerce 正常
