# 3-域名与主机

> 这块是独立站的"门牌 + 地基"。域名是门牌（别人找到你），主机是地基（站住得住）。

## 这里放什么
- `域名-namesilo/` —— 你在 namesilo 买的域名账号、续费到期日、账号找回信息
- `主机-阿里云国际/` —— 服务器选型、配置、开通记录、SSH 密钥、IP 地址
