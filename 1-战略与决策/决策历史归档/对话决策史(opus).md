## 2026-06-09：收款路线调研结论

**两条路**：
| | 🅰 大陆公司+第三方收单 | 🅱 境外主体+Stripe |
|---|---|---|
| 体验 | PayPal 偏跳转 / Airwallex 站内卡输入 | 行业标杆、转化最好 |
| 起步成本 | 开户基本免费 | 美国 Atlas ~$500+ |
| 税 | 境内交、9610 综试区税负低 | **CRS + 金税四期正在大规模追缴** |
| 适合时机 | **现在起步** | 起量后再升级 |

**核心结论**：
- 大陆主体开不了 Stripe（不是"难"，是"不开放"）
- 想用 Stripe 唯一出路 = 注册境外公司 + 扛全球纳税
- 钱能收到不是问题，"到了境外之后"才是真问题
- **建议起步走 🅰 路线**：先 PayPal 打通"能收钱"→ 主力收单上 Airwallex

**贸易方式定型**：9610 跨境电商零售出口（综试区注册 + 无票免税 + 企业所得税核定 4%）

## 2026-06-11：竞品调研（详情页 / 定价 / 运费破损退换）

**三件大事**：

### 1. 战略洞察（最值钱的一条）
西方资深茶友对"日用盖碗"心理价 = **$25-50**。
👉 $100+ **不能当"更好用的盖碗"卖**，要当"收藏价值 / 独家设计 / 送礼仪式感"卖。
👉 **店做成"瓷器艺术品 / 礼品"，不是"茶具用品"**。

### 2. 详情页八件套（每件都按这个填）
1. 参数三件套（容量 ml + 尺寸 + 泥料/重量）
2. 匠人/工作室署名 + 底款照片（撑高价第一支柱）
3. 工艺流程 + 难度量化（"烧后收缩 30-40% 仍要严丝合缝拼合"）
4. 一段匠人故事（学 Eastern Leaves 的 Da Juan 写法）
5. 典故背书（甜白=明永乐、霁红、御窑）
6. 保养说明（"只手洗、不用洗洁精"）
7. 手工差异预期管理（把"不一致"转成"独一无二"，降低退货）
8. 图片（白底多角度 + 底款特写 + 注水/上手场景）

### 3. 定价分层（带真实锚点）
- $0-49 引流/凑单（Yunnan Sourcing $6.75 盖碗）
- **$129-199 主力收藏（white2tea $129 / MoriMa $157 / Mud and Leaves $139-189）**
- $249-349 送礼/旗舰（Mud and Leaves 青花套 $299）
- $400-1500+ 镇店孤品（Meimei 影青套 $780 / 心经盖碗 $1,549）

### 4. 破损退换政策（China 直发卖家的三套）
| | 报损时限 | 怎么处理 |
|---|---|---|
| **Bitterleaf** | **48 小时** | 免费补发 / 全额退款 / 替代，**买家零成本** |
| **Yunnan Sourcing** | 14 天 | 换发或退款；外观瑕疵最多退 50% |
| **white2tea** | 未明文 | 官网无明文破损政策；flat $9.99 邮、3-5 周到 |

**👉 给你的推荐（高客单 + 陌生站 = 信任投资）**：
1. 签收后 48 小时内报损（窗口短、抄 Bitterleaf）
2. 必须提供照片 / 开箱视频
3. **运输破碎 → 免费补发或全额退款**（这份"大方"是必须的，别抠）
4. 外观小瑕疵 → 部分退款/小额补偿
5. **自然手工差异不属破损**（提前在详情页声明）
6. 包装做成卖点（"博物馆级防碎包装"明示）
