## 🟡 7–8月 景德镇(1–2 个月)
一趟把「货 + 内容 + 发货」全办了。

1. 选品定款:挑能讲故事、适合送礼 / 收藏、相对结实好打包的款做主推。
2. 谈供货 + 谈代发:订单来了,厂家 / 经销商能不能直接帮你打包发美国。
3. ⭐ 谈破损责任:碎了谁赔(厂家 / 货运 / 你),白纸黑字谈死。
4. 玩命拍素材:产品图 + 视频,站和 TikTok 都靠它喂,越多越好。
5. ⭐ 自己寄 1–2 件样品到美国(找朋友收):实测专运破损率、到货时间、开箱效果,再定主推款和运费。
6. 算清成本账:拿货 + 专运 + 包装 + 收款手续费 + 破损损耗,看 $100+ 还剩多少利润。

## 几句掏心窝的提醒(这三条比上面更重要)
1. **顺序的命门:先确认收得到钱,再埋头搭站。**(收款已查实，见调研文档)
   好消息：走 🅰 路线，PayPal / Airwallex 都能接入自建站，**用 Claude Code 自建在收款上没有硬障碍**。
   体验差异：PayPal 偏"按钮跳转"；Airwallex 可做站内刷卡、转化更好。
   注意：**大陆主体开不了 Stripe** —— 想用 Stripe 得有境外公司，且要扛境外税务那一摊。
2. **高客单 + 陌生站 = 信任是第一道坎。**
   美国人在一个没听过的站掏 $100+,支付页面、退换政策、真实开箱视频,每一样都在帮你取信。
   这也是 TikTok 的真正价值 —— 不只是导流量,是先让人信你。
3. **易碎 + 跨境,破损是利润杀手。**
   专运贵、还可能碎,两刀都砍在利润上。所以景德镇那趟,「碎了谁赔」和「寄样品实测」是重中之重。
