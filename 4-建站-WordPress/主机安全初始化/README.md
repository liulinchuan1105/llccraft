## 起手流程(顺序)

1. **老板付款** → 拿到 **公网 IP + 初始 root 密码**(一次性密码,**别留在仓库**)
2. **下载密钥**(`ssh-keygen` 在老板本地生成 `id_ed25519.pub`,贴到 ECS `authorized_keys`)
3. **跑加固脚本**:`ssh root@<NEW_IP>` 用初始密码首登 → 把 `Ubuntu22-安全加固脚本.sh` 拷过去 → 替换占位符 → 执行
4. **验证第二终端**:用 `ssh -i ~/.ssh/id_ed25519 -p <NEW_SSH_PORT> <NEW_USER>@<NEW_IP>` 登入 → 确认密钥能用
5. **旧终端关闭**:确认新终端稳后,旧 root 登入窗口关掉
6. **同步安全组规则**:阿里云控制台 → 安全组 → 放行 `NEW_SSH_PORT` + 80 + 443(只对 `your_admin_ip_cidr_placeholder` 开 SSH)
7. **建私密凭据文件**:账号 + 密码 + 密钥路径 → 存本机加密盘或 1Password,不入 git

## 关键提醒

- 🔴 **新机器第一时间改 SSH 端口 + 禁密码登录**(互联网裸奔的机器 5 分钟就被扫)
- 🔴 **SSH 别对 0.0.0.0/0 开** —— 只对你家/办公室出口 IP 开
- 🔴 **宝塔后台别用 8888 默认端口** —— 改一个随机 5 位数
- 🔴 **root 初始密码别留在仓库** —— 用占位符或存到 namesilo/密钥笔记
- 🟢 **fail2ban 默认足够**,不需要额外调参
- 🟢 **公网 IP 用弹性 IP** —— 出问题可解绑换 ECS,域名 A 记录不用动
