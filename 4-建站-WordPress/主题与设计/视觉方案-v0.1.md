## 🎨 视觉语言完整规格

### 配色(7 token)

| Token | Hex | 用途 |
|---|---|---|
| `ink` | `#0e0e0e` | 标题 / 边框 / 主要文字 |
| `paper` | `#faf8f3` | 背景(米白)|
| `dust` | `#e8e1d4` | 分隔线 / 占位背景(沙)|
| `accent` | `#a8323f` | 细节点缀(霁红 · hover/underlines)|
| `celadon` | `#aac4b0` | 可选用(影青绿)|
| `white` | `#ffffff` | 留白 fallback |
| `black-30` | `rgba(14,14,14,.3)` | hover 阴影 |

### 字体(2 主 + 1 mono)

| 字体 | 来源 | 用途 |
|---|---|---|
| **Cormorant Garamond** | Google Fonts · serif | 标题 / 副标 / 衬线落款 |
| **Inter** | system / Google Fonts · sans | 正文 / UI 标签 / 价格 |
| **JetBrains Mono** | Google Fonts · mono | (预留,Phase 3 偶尔需要)|

### 字级(h1-h4 + button)

```css
h1:  clamp(2.5rem, 6vw, 5.5rem)    /* hero */  letter-spacing: -0.02em; weight: 500
h2:  clamp(2.0rem, 4vw, 3.0rem)    /* section */
h3:  0.75rem  tracking: 0.2em    /* SMALL CAPS 标签 */
h4:  default
p:   1.0625rem  line-height: 1.7
small: 0.875rem
```

### 间距(垂直 rhythm 8px 倍数)

```
section-pad 默认:   py 16 (mobile) / py 24 (md) / py 32 (lg)
hero-frame 高度:  min-h 70vh (mobile) / min-h 80vh (md+)
两列间距:        gap 12
四列间距:        gap 8
卡片内 padding:   p 6 (mobile) / p 8 (md+)
```

## 🧱 6 个自建 component class(实物 spec)

```css
/* 1. 主按钮 */
.btn-primary {
    @apply inline-flex items-center justify-center 
           px-8 py-3 text-sm font-medium uppercase tracking-wider
           border border-ink bg-ink text-paper
           transition-colors duration-300 ease-soft
           hover:bg-accent hover:border-accent hover:text-paper;
}
/* 用法:<a class="btn-primary" href="/shop/">Browse</a> */

/* 2. 产品卡片 */
.product-card {
    @apply bg-paper transition-shadow duration-300 ease-soft
           hover:shadow-[0_2px_24px_-12px_rgba(14,14,14,0.18)];
}
/* 用法:figure class="product-card" + img + .product-card__price 文字 */

/* 3. section 上下间距 */
.section-pad {
    @apply py-16 md:py-24 lg:py-32 px-6 md:px-10
           max-w-gutter mx-auto w-full;
}

/* 4. hero 边框 */
.hero-frame {
    @apply min-h-[70vh] md:min-h-[80vh] 
           flex flex-col items-center justify-center
           border-t border-ink px-6;
}

/* 5. 斜体衬线 */
.italic-serif {
    @apply font-serif italic tracking-tight text-ink/90;
}

/* 6. 文本均衡 */
.text-balance {
    text-wrap: balance;
}
```

## 🎬 设计原则 5 条(审计口径)

1. **零画笔振幅** — 所有 spacing / sizing 用 Tailwind utility + clamp()，不允许手写 px
2. **零组件默认发胖** — 不装 DaisyUI / 不装完整 Sage · 自建 6 class 就够
3. **零页面构造器** — 不装 Elementor / WPBakery · 全 Gutenberg Block Pattern
4. **零图像预嵌入** — 占位背景 `bg-dust` 即可 · 等回景德镇真图替换
5. **零冗余字体** — 只用 2 主字体 + 1 mono fallback
