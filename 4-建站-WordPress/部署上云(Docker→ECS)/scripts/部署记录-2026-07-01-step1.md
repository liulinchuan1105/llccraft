### Step 1 用 cmd //c 绕开 bash 中文路径翻译(踩坑记录)

| 坑 | 解决方案 |
|---|---|
| bash `cd 中文path` 出错(exit code 2)| `pushd "$SCRIPT_DIR"` 抓绝对路径 |
| bash `docker exec ... -C /var/www/html` 把 `/var/www/html` 翻译成 `C:\Program Files\Git\var\www\html` | **改用 `cmd //c "docker exec ..."`**(Windows path 直接走 Win32 API) |
| bash `docker cp ... /tmp/wp-source.tar.gz` 把 dest 路径翻译成 `C:\\tmp\\wp-source.tar.gz` | **改用 `cmd //c "docker cp ..."`** + 落 Windows path + cp 到 `/tmp` |
| PowerShell 内中文 path 也有 UnicodeDecodeError bug | 用 cmd //c 而非 PowerShell |
| Python 3.12 内部 UTF-8 path resolution 在中文挂掉 | **不用 Python;全程 bash + cmd //c** |

**重要教训**:`4-建站-WordPress/` 子目录中文(策略:`主题与设计` / `子主题(Child Theme)`)在 Git Bash + Docker 这种**双重 MINGY 路径翻译**场景下要绕开。原 `1-backup-local.sh` 经过几次演变为最终 `cmd //c` 主导版本,落档在仓库,下次美西硅谷跑同样的中文路径也不会再撞。
