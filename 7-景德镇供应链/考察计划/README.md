# 考察计划

> 出发前 1 周填。行程、目标、待访厂商、要谈的事、要问的问题，**全列出来**——到时候现场不慌。

## 这里放什么
- **行程**：哪几天在哪、约了谁
- **待访厂商清单**（名字 / 工艺线 / 地址 / 微信 / 联系人）
- **每家要谈什么**（代发 / 破损责任 / 铅镉报告 / 价格区间）
- **要拍什么**（产品 / 匠人 / 工序 / 工厂）
- **要带回什么**（样品 / 报价单 / 合同 / 印刷品）
- 应急联系（住宿 / 当地朋友 / 备用方案）

## 出发前一周清单（按这个填）

### 1. 行程框架
- 出发日 / 到达日 / 住宿 / 返程日
- 在景德镇待几天 → 周围（瑶里 / 浮梁）要不要顺便看

### 2. 待访厂商（至少 5 家备选）
- 工作室 / 经销商 / 包装厂
- 工艺线筛选（按 `5-选品与内容/选品/README.md` 的三条线）
- 怎么联系（本地朋友介绍 / 抖音 / 小红书查 / 你之前有没有打过交道？）

### 3. 每家必谈 6 件事
| 议题 | 关键问题 |
|---|---|
| **代发** | 能不能帮你直接打包发美国？ |
| **破损责任** | 碎了谁赔、赔多少？白纸黑字 |
| **铅镉检测** | 有没有 FDA / 加州 Prop 65 报告？ |
| **底款署名** | 能不能盖章底款（作坊名 / 匠人名）？ |
| **价格区间** | 主推款拿货价范围？ |
| **起订量 / 账期** | 有没有最低拿货？月结？现结？ |

### 4. 拍照计划
- 🟡 每款产品：**正面 + 内壁 + 底款 + 包装**（4 张起步）
- 🟡 工序视频：**手拉坯 / 利坯 / 上釉 / 出窑**（每段 30 秒）
- 🟡 匠人访谈（中英字幕）：他来自哪里 / 学艺多久 / 为啥做这行
- 🟡 工厂全景：外景 + 内景 + 工具陈列

### 5. 带回清单
- [ ] 样品（每款至少 1 件，带到美国寄）
- [ ] 报价单
- [ ] 厂家营业执照 / 食品接触安全报告（如有）
- [ ] 厂家微信名片

### 6. 应急
- [ ] 当地住宿（提前订）
- [ ] 当地朋友 / 联系人
- [ ] 备用资金（拿样要现款）
- [ ] 包装物料（如需要当场定）
