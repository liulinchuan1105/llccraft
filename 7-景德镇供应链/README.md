# 7-景德镇供应链

> 7-8 月去景德镇的**所有现场材料**都集中在这。
> 这一趟决定你"卖什么 + 怎么卖"两大命门——选品定款 + 破损责任谈死。

## 这里放什么
- `考察计划/` —— 出发前的行程、待访厂商清单、目标、问题清单
- `供应商信息/` —— 每家工作室 / 经销商的名字 / 联络 / 报价 / 工艺线 / 合作意向
- `素材库/` —— 产品图、视频、工厂照片、底款特写
- `成本账/` —— 拿货 + 包装 + 专运 + 收款手续费 + 破损损耗 = 单件真实成本

## 这一趟的"6 个必须达成"
1. ⭐ 选品定款（3-5 款主推 + 1-2 款孤品）
2. ⭐ 谈代发（厂家 / 经销商能不能直接帮你打包）
3. ⭐ **谈破损责任**——白纸黑字谈死（碎了谁赔、赔多少）
4. ⭐ 玩命拍素材（产品图 + 视频，能拍多少拍多少）
5. ⭐ **寄 1-2 件样品到美国实测**（找朋友收、看破损率 + 时效）
6. ⭐ **算成本账**（拿货 + 专运 + 包装 + 手续费 + 破损损耗 = 真实成本）

## 关键提醒
- 🔴 6 个里头，**谈破损责任 + 寄样实测 + 算成本账**是 opsium 提醒过的命门
- 🔴 厂家的"含铅镉溶出检测报告"一定要拿到（美国 FDA + 加州 Prop 65 强制）
- 🟡 越早把行程整理出来，到时候越不慌——出发前一周先把 `考察计划/` 填满
