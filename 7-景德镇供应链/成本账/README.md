# 成本账

> 一件瓷器从景德镇到美国客户手里，**真实成本是多少**——这个账决定 $100+ 还剩多少利润。
> 算不平这账，就不开张。

## 单件真实成本拆分（要算到 1 美分）

```
# 单件成本账 · [产品名]

## 拿货成本
- 拿货价：¥ XXX
- 加价（如果经销商代发）：¥ XXX

## 国内段
- 包装（珍珠棉 + 瓦楞 + 纸盒）：¥ XX
- 国内运到货仓 / 厂家直发：¥ X
- 报关 / 三单登记：¥ X

## 国际段
- 瓷器海外专运（按重量计）：¥ XX
- 保价（按货值 X%）：¥ X

## 收款环节
- 支付通道手续费（PayPal/Airwallex 约 3.3%-4.4%）：$X
- 提现到对公账户（如有）：$X

## 损耗预留
- 破损率（按寄样实测估算，比如 5%）：预留 X% 货值
- 退款预留（比如 3%）：预留 X% 货值

## 隐性成本
- 你自己的时间
- 营销（先不算）
```

## 关键决策（算完才知道怎么定）

| 算出结果 | 怎么定 |
|---|---|
| 真实成本 ≤ 拿货价 × 2.5 | 💚 $100+ 有戏，可以试 |
| 真实成本 ≈ 拿货价 × 3 | 🟡 紧巴巴，要么涨价要么优化 |
| 真实成本 > 拿货价 × 3.5 | 🔴 没利润，跳过这工艺/款 |
