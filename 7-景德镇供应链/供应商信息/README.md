# 供应商信息

> 景德镇现场每见一家工作室 / 经销商，**都建一张卡片**存进这。
> 谈代发、谈破损责任、谈价格，**有记录才有依据**。

## 这里放什么

按"**一厂一文件**"原则：
- `工作室A-清可轩.md`、`工作室B-沈铧.md` 这种命名
- 每个文件放：基本信息 / 工艺线 / 主推款 / 拿货价 / 合作模式 / 联系人 / 备注

## 一家工作室一张卡片（必填项）

```
# [工作室/厂名]

## 基本信息
- 工艺线：[玲珑 / 青花 / 霁红 / 影青 ...]
- 位置：[景德镇市 X 区 X 路]
- 主理人 / 联系人：[名字 + 微信 + 电话]
- 来源：[朋友介绍 / 小红书 / 抖音 / 实地路过]

## 拿货报价
| 款 | 拿货价 | 备注 |
|---|---|---|
| X 盖碗 | ¥XXX | 起订 X 件 |
| Y 小壶 | ¥XXX | 可定款 |

## 合作模式
- ⭐ 代发：[能不能帮你打包发美国？能 / 不能 / 部分能]
- ⭐ 破损责任：[碎了谁赔 / 怎么赔 / 白纸黑字]
- ⭐ 底款署名：[能不能盖章 / 加什么内容]
- 账期：[现结 / 月结 / 季结]
- 起订量：[X 件]

## 检测报告
- [ ] FDA 铅镉溶出：[有 / 无 / 待补]
- [ ] 加州 Prop 65：[有 / 无 / 待补]

## 拍到的素材
- 产品图：[路径 or 描述]
- 工序视频：[路径]
- 匠人：[名字 + 视频路径]

## 综合评估
- 推荐度：⭐⭐⭐⭐⭐
- 适合做：[主推款 / 引流款 / 孤品]

## 后续动作
- [ ] 寄样到美国
- [ ] 二次谈价
- [ ] 签代发合同
```
