## 这里放什么

- `01-产品图/` —— 单品白底图 + 多角度 + 底款

- `03-匠人访谈/` —— 中英字幕版
- `04-工厂全景/` —— 外景 / 内景 / 工具
- `05-破损包装实测/` —— 寄样打包装 + 美国收件开箱视频

## 必拍清单（每款产品都拍这 5 张）

1. ✅ 白底正面（棚拍或自然光）
2. ✅ 内壁俯拍
3. ✅ **底款特写**（撑高价的命门素材）
4. ✅ 上手持杯 / 注水（用感）
5. ✅ 与手 / 茶宠 / 茶席搭配
