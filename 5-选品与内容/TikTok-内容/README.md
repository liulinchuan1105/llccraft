## 这里放什么
- TikTok 选题记录（哪几条爆了 / 为什么爆）
- 视频脚本（每周排几期）
- 拍摄计划（去景德镇当周拍什么）
- 主页挂站信息（bio 文案、链接）
- 评论区回复话术（高频问题 FAQ）

## 视频脚本模板（每条 60 秒内）

```
00:00  钩子（3 秒）：反常识 / 问题 / 视觉冲击
00:05  转折：背景
00:15  主体：今天聊的
00:45  行动：链接 in bio / 评论关键词
01:00  结尾：悬念（下一条）
```
