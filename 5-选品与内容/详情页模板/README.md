# 详情页模板

> 每一个上架产品的详情页，**都按这个八件套写**——这是竞品调研给的"抄作业"模板。
> 没产品图的阶段，先把这八件套的框架列出来，等景德镇产品图回来往里塞。

## 八件套（直接抄自竞品调研）

每款产品详情页必须包含这 8 块：

### 1. 参数三件套
- 容量：**ml**（懂茶玩家第一眼看的）
- 尺寸：高 mm × 径 mm
- 泥料 / 重量

### 2. 匠人 / 工作室署名 + 底款照片
- 撑高价的**第一支柱**
- 例：「景德镇清可轩工作室手作，盖碗底有工作室署名」
- **底款特写图必备**

### 3. 工艺流程 + 难度量化
- 写「手拉坯→阴干→修坯极薄→高温 1300℃→上釉→复烧」
- 量化难度：「烧后收缩 30-40% 仍要严丝合缝拼合」「霁红釉废品率极高」
- **把成本讲清 = 把高价讲合理**

### 4. 一段匠人故事
- 师承 / 迁居景德镇 / 为本店联名共创
- **学 Eastern Leaves 的 Da Juan 写法**

### 5. 典故背书
- 釉色器型挂朝代：
  - 甜白 = 明永乐
  - 霁红 = 明宣德
  - 御窑 = 清
  - 影青 = 宋
- **给收藏感**

### 6. 保养说明
- 固定写「只手洗、不用洗洁精」
- 未上釉/紫砂写「会随使用养色出包浆」

### 7. 手工差异预期管理（**抄 Song Tea 原话**）
- 「每件在色调、质地、尺寸上略有不同，厚釉区/发色差异属正常」
- **把"不一致"转成"独一无二"卖点**，同时降低退货纠纷（**一举两得**）

### 8. 图片清单（每张都拍）
- ✅ 整体（多个角度）
- ✅ 俯拍内壁
- ✅ 盖碗分件
- ✅ **底款特写**
- ✅ 注水 / 上手使用场景（营造使用感）
