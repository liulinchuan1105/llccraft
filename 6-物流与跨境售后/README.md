# 6-物流与跨境售后

> 瓷器 + 跨境 = **破损是利润杀手**。
> 这块直接决定：运费怎么标、退换怎么写、碎了谁来赔。
> **占位站阶段**先写好退换政策页，等景德镇寄样实测后再定死数字（保价、时限、赔付比例）。

## 这里放什么
- `瓷器海外专运(对比)/` —— 各家专线报价、时效、破损率对比
- `破损退换政策/` —— 站内政策页文案（套竞品调研结论的推荐措辞）
