# 瓷器海外专运（对比）

> 你这种"瓷器 / 易碎品 / 中国直发美国"的专线，国内有几家专门做。
> 这事要**对比 + 寄样实测**才能下结论，所以现在只能列个调研框架。

## 这里放什么
- 各家专线的报价单（询价邮件 / 电话沟通记录）
- 时效对比（美国西海岸 / 东海岸 / 中部）
- 破损率（**实测说了算**——景德镇寄 1-2 件样品到美国朋友处）
- 保价方案 + 赔付条款
- 包装建议（谁来做 / 多大箱 / 怎么填）

## 调研维度（对比表）

| 维度 | 问他们什么 |
|---|---|
| **单价** | 0.5-2 kg / 2-5 kg / 5-10 kg 各档报价 |
| **时效** | 美国西海岸 / 东海岸 / 中部 各档 days |
| **破损率** | 你们的统计数据（如果有）+ 索赔流程 |
| **保价** | 买保价的费率 + 赔付条件 |
| **是否代打包** | 厂家能不能直接交付给他们 |
| **赔偿条款** | 碎了赔多少 / 怎么赔 / 多久赔 |
| **揽收** | 景德镇 / 佛山 / 深圳 哪家能到景德镇取货 |

## 你要联系的方向（举几个例子）

- **云途物流**（YunExpress）—— 大件小件都收
- **顺丰国际**——贵但稳
- **燕文物流**——义乌小包起家
- **UBI / 利通**——专门做易碎品
- **百运达**——中大件

> ⚠️ 没真打过样就不知道哪家真稳——别只看广告。

## 关键提醒
- 🔴 **一定要问"易碎品索赔条款"**——别只问价格
- 🔴 **保价必买**——$100+ 的瓷器，没有保价心里慌
- 🟡 包装你定规格 + 厂家照做 + 专线加固 = 三道保险

## 关键决策点（待景德镇定盘）
- 主推 1-2 家主力 + 1 家备用
- 运费在商品页标"包邮"还是"另算"？（**$100+ 一般包邮更利转化**——你看 white2tea flat $9.99、Yunnan 也都是包邮）
- 时效承诺怎么写（**别夸大**——写"3-5 周"留缓冲，Yunnan 写的就是这个）
